## ​ Getting Started

```bash
# 1) Clone the repository
git clone https://github.com/miladmo68/Expense-Tracker.git
cd Expense-Tracker

# 2) Install dependencies
npm install

# 3) Start development server
npm run dev

# 4) Build for production
npm run build
